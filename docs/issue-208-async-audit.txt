Static trace
Home marks failure synchronously, restores the board position, and retains a queue/card/revision-specific marker before asynchronous flush. Completion reads current store failure state, freezes an Again/guided review and logical attempt identity before its delivery timer. Queue initialization overlays matching saved failure contexts, preserving guidance even when the server flag is still false. Failure outbox replay keeps its operation identity across transient delivery failures. Guided review delivery has an independent failure-marker operation, and its explicit guided result remains authoritative when an advisory marker conflicts. PostgreSQL marker validation follows card-before-queue locking and checks retained identity. Review receipts bind logical attempts; independent competing attempts are reconciled separately. Two different attempts are legitimate separate review rows; replay of either must not create another row. These static observations do not prove real database concurrency.
