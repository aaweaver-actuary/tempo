# Saved-source authoring navigation

This package currently contains only its [initializer](__init__.py); the former
Discovery acceptance application is retired. Do not import a nonexistent
`authoring.discovery` owner or infer Discovery availability from this directory.

Current saved-source conflict and mutation policy lives in
[repertoire changes](../repertoire/changes/README.md), with concrete persistence in
[tempo_storage authored repertoires](../../../database/tempo_storage/authored_repertoires).
[Authored Studies](../studies/README.md) and daily Study are distinct concepts.
These are source pointers, not claims of complete domain isolation or deployment.
