# Explicit synthetic C corpus

`producer: synthetic` identifies invented games/activation IDs for classification
and lifecycle development. These are not Andy's games, A artifact acceptance,
Learning activation, engine executions or training-benefit evidence. `generate.py`
reproduces the normalized manifest/pages using the installed public model shapes.
The owning native suite produces Workbench fixture JSON from actual installed C
and disposable PostgreSQL, separately from these source fixtures.
