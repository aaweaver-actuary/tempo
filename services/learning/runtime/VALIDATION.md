# Validation record

Results are filled from the final recorded commands before handoff. Machine-readable evidence is preserved outside the disposable checkout, with source hashes, artifact identities, toolchain versions, exact inventories and cleanup results.

The test fixture uses only invocation-owned PostgreSQL. Browser proof covers the existing review-client/API seam; the complete Study UI, D's full recovery acceptance, E's shared runner integration, hosted CI/branch protection and live cutover remain separate acceptance. The configured tablebase protocol is tested with a local HTTP provider; availability or correctness of the public Lichess service is not claimed.
